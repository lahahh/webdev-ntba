# Homework 02: Setting Up Your Project Folder

Create the lowercase `project/` structure with `index.html`, `about.html`, `contact.html`, `activities.html`, `media.html`, `css/`, and `images/`. Initially build the home, about, and contact pages with valid HTML5, club content, and plain root-level links. Add at least two appropriately licensed images with descriptive `alt` text to the home page after Session 3.

Check naming conventions and relative paths. Save with `git add project/`, commit `HW2: Set up project folder structure`, and push.
