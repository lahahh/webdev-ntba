# Homework 14: CSS Dropdown Navigation

Add a CSS-only dropdown menu to the navigation, with a nested list of useful About-page anchors. Style the parent as relative, hide the submenu by default, reveal it on hover, style submenu links, and add a transition. Integrate the menu on at least two pages. Optionally add a Back to Top link and `id="top"` on the header.

Save with `git add project/`, commit `HW14: Add interactive dropdown menu`, and push.
