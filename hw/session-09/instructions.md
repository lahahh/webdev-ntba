# Homework 09: Creating HTML Tables

Create `project/activities.html` with a caption, `thead`, `tbody`, at least five columns, at least five data rows, and at least one `colspan` or `rowspan`. Style the table with full width, collapsed borders, cell padding, colored headers, zebra striping, and row hover. Add an Activities link to every page.

Save with `git add project/`, commit `HW9: Add schedule page with styled table`, and push.
