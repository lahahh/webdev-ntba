# Homework 01: My First Web Page

Create `homework/session-01/index.html` with a complete HTML5 boilerplate, your name in the title and an `h1`, an `h2`, at least three paragraphs, and an HTML comment. Use only the tags taught in Session 1.

Also create empty `css/` and `images/` folders with `.gitkeep` files. Check nesting, indentation, and the browser tab title. Save with `git add homework/session-01/`, commit `HW1: Add first web page`, and push.
