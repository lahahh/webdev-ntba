# Homework 07: Typography with Google Fonts

Choose heading and body fonts, add the Google Fonts link to all three pages, and apply the fonts in `project/css/style.css`. Create a clear size and weight hierarchy, readable line height, styled links with hover behavior, and well-spaced lists. Keep fallback fonts; the final project must also work offline.

Save with `git add project/`, commit `HW7: Add Google Fonts and improve typography`, and push.
